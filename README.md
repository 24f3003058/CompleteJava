# CompleteJava

A collection of Java programs written while learning core and object-oriented Java — covering language fundamentals, OOP concepts, exception handling, multithreading, and a few small simulated applications.

## Structure

```
CompleteJava/
├── basics/               # Fundamentals: I/O, strings, control flow, calculators
├── oop/                  # Classes, inheritance, cloning, employee models
├── exception-handling/   # Custom exceptions, try/catch, robust input handling
├── multithreading/       # Thread creation and execution examples
└── mini-projects/        # Small simulated apps (admission system, e-commerce,
                           # employee portal, investment app, voter validation)
```

## Topics covered

- **Basics** — Hello World, area calculation, string operations, series sums, simple calculators
- **OOP** — Employee class hierarchies, object cloning, inheritance
- **Exception Handling** — Custom exception classes, defensive/robust program design
- **Multithreading** — Basic thread lifecycle and execution
- **Mini Projects** — Small console-based systems that model real-world workflows (admissions, e-commerce, investments, voting)

## Running a file

Each program is self-contained. Compile and run any file directly:

```bash
cd basics
javac Helloworld.java
java Helloworld
```

## Notes

This is a learning repository built incrementally as part of coursework — code quality and design evolve across files as concepts were introduced. Compiled `.class` files are excluded via `.gitignore`.
